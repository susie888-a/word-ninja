# Historical UI versions

These files are retained solely for version history and comparison. GitHub
Pages publishes only `public/`, so none of the pages in this folder are live.

The current runtime does not depend on any file here. The verified release
chain is documented in [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).

| Files | Historical role |
| --- | --- |
| `app-v4.html`, `app-v5.html`, `app-v8.html`, `app-v10.html` | early UI iterations |
| `app-v12.html`, `app-v13.html`, `app-v14.html` | intermediate wrapper iterations |
| `app-v16-live.html` | abandoned v16 live branch; not the verified preview entry |
